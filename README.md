# 茨城県公立図書館データベース (Ibaraki Public Libraries Database)

茨城県内の公立図書館（県立・市町村立・中央館・地域館・分館）を網羅したオープンデータベースです。

## 編纂・著作者
- **小松崎 浩司** (Hiroshi Komatsuzaki)
- 作成支援: Google Gemini
