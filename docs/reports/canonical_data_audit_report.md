# 茨城県公立図書館データベース 独立監査および批判的再調査報告書

## 1. 監査の目的と範囲
本報告書は、茨城県全44市町村の公立図書館・主要公民館図書室を収録したCanonical Data（`data/libraries/*.yaml` 全44ファイル、計100施設）について、原資料との同一性、スキーマ整合性、統計集計単位、未確認情報の区別を独立監査した結果を記録するものである[1][2]。

## 2. 独立監査で発見された不整合と是正措置

### 2.1 スキーマ構造および統計集計単位の統一
- **原因**: 初期に作成した優先12市町のYAMLと、後続の32市町村のYAMLの間で、`category`、`statistics` ネストブロック、`history`、`field_sources` の有無に差異が生じていた。また、土浦市[3][4]・石岡市[5]・常陸太田市[6]・つくば市[7]・鹿嶋市[8]・守谷市[9]・かすみがうら市[10]・鉾田市[11]・つくばみらい市[12]の9市における蔵書数は、分館・分室を含むシステム合算値（`system_aggregate`）であるにもかかわらず、単館統計（`facility_level`）と区別されていなかった[1]。
- **修正**: 全44市町村・全100施設のYAMLを統一スキーマへ移行し、`statistics.scope` に `facility_level`（57施設）、`system_aggregate`（9施設）、`not_applicable`（34施設）を明示した[1][2]。

### 2.2 『令和７年度茨城の図書館』テキスト抽出時の行ズレ・列取り違えの是正
- **原因**: 初回抽出時にPDFテキスト抽出ツールの段組み順序の乱れにより、以下の取り違えが発生していた[1]。
  1. 公共図書館所蔵資料数表（pp. 20-21）において、No. 41（坂東市立猿島図書館：正しくは115,322冊）[1][13]、No. 43（かすみがうら市立図書館：正しくは130,736冊）[1][10]、No. 44（桜川市立図書館：正しくは66,633冊）[1][14]、No. 48（鉾田市立図書館：正しくは92,315冊）[1][11]、No. 50（小美玉市小川図書館：正しくは80,971冊）[1]、No. 51（小美玉市玉里図書館：正しくは47,277冊）[1]の数値が隣接行や開架冊数列と入れ替わっていた。
  2. 公民館図書室表（pp. 40-42）において、印刷p. 40の「奉仕人口（千人）」列を「閲覧席数」と誤読し、印刷p. 42の「令和6年度個人貸出冊数」を「所蔵資料数」と誤読していた[1]。
  3. 優先12市町の一部本館（水戸市内原図書館[1][15]、土浦市立図書館[1]、石岡市立中央図書館[1]、常陸太田市立図書館[1]、つくば市立中央図書館[1]、坂東市2館[1][13]、稲敷市立図書館[1][16]、行方市立図書館[1][17]、鉾田市立図書館[1][11]、つくばみらい市立図書館[1][12]）の延床面積・閲覧席数・開館年月に旧値または概算値が残存していた。
- **修正**: 『令和７年度茨城の図書館』の原本テーブルを視覚的に全行再照合し、一般図書・児童図書・郷土資料・視聴覚資料の内訳合計検算を実施したうえで、全100施設の数値を原本通りに完全修正した[1]。更新前後の差分は `data/history/diff_20261015_canonical_audit.patch` に保存した。

### 2.3 原資料（古河市三和図書館）における印字不整合の検出と記録
- **発見事項**: 『令和７年度茨城の図書館』p. 20（No. 13 古河市三和図書館）では、「資料総数」欄に `33,651` と印字されているが、同ページの「うち一般図書 `233,879` ＋ うち児童図書 `91,790` ＋ うち郷土資料 `2,503` ＋ うち視聴覚資料 `10,843`」を合算すると `339,015`（郷土資料を内数とした場合は `336,512`）となり、原資料側の資料総数欄における末尾1桁脱落と考えられる[1][18]。
- **処置**: 原資料の印字値を勝手に改変せず、`collection_count: 33651` として原資料値を保持したうえで、`breakdown` 内に内訳各値と計算合計値（`calculated_sum_without_local: 336512`, `calculated_sum_with_local: 339015`）および `discrepancy_note` を併記した[1][2]。

### 2.4 批判的再調査による拠点網羅性の拡充と未確認項目の明示
- 第2巡の自治体公式資料調査により、かすみがうら市の千代田分館・下稲吉コミュニティセンター窓口[10]、古河市の社会教育施設課所管5図書室（とねミドリ館、つつみ館、古河断熱中田公民館、ユーセンターKI総和、総和地域交流センター）[18]、桜川市の桜川市立図書館条例[14]、大子町の図書館「プチ・ソフィア」（中央公民館別館図書室）[19]を一次資料から追加検証した。
- 全ての施設について、未確認項目が1つでも残る施設（80施設）は `verification.status: "partially_verified"` とし、`unverified_fields` に未確認項目名を列挙することで、全項目検証完了施設（20施設、`verified`）と厳格に区別した[2]。
